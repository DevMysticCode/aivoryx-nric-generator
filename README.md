# Aivoryx Singapore NRIC/FIN Generator

Standalone microsaas for generating and validating Singapore NRIC/FIN test data.

## Run locally

```bash
npm run dev
```

Open `http://localhost:5174`.

## Deployment

Deploy the folder as a static site or behind the included `server.js`. Suggested production host:

`https://nric-generator.aivoryx.com`

The tool is client-side only. It does not upload generated or validated values.
